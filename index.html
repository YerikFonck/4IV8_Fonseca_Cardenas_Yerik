El portafolio de evidencias tiene como propósito documentar y demostrar el aprendizaje obtenido durante el curso de Nuevas Tecnologías. aqui reuni las prácticas desarrolladas durante el semestre, organizadas de forma progresiva, desde el manejo básico de HTML y CSS hasta la implementación de aplicaciones web MVC, Express.js y MySQL. Cada práctica demuestra la aplicación de conceptos vistos en clase y el desarrollo de habilidades en programación web, lógica algorítmica, diseño de interfaces y construcción de sistemas de gestión de datos.
